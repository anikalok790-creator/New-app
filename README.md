# SnapPro Downloader

A powerful video and audio downloader app built with Python Flask and optimized for WebToApp (Android WebView).

## Packages Installation

To install the required packages, run the following command in your terminal:

pip install -r requirements.txt

## How to Run

1. Ensure Python is installed on your system.
2. Install the dependencies: pip install -r requirements.txt
3. Start the server: python app.py
4. Open your browser and go to http://127.0.0.1:5000

## Features
- High-quality video downloading (up to 4K/8K/16K).
- Supports audio extraction.
- Built-in proxy for WebView downloads.
- History and local file management.
